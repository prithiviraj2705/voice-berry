# Voice Berry

A multilingual voice-enabled application that transcribes speech, translates it into English, collects user contact details, and sends structured query submissions to a support team.

## 🚀 Tech Stack
* **Frontend:** React + TypeScript + Vite
* **Backend:** Node.js 
* **Database:** Supabase
* **Linting:** Oxlint (Type-aware linting enabled)

## 📂 Project Structure
* `/frontend` - React/Vite client application.
* `/server` - Backend logic and API integrations for voice processing.
* `/scratch` - Experimental code and temporary workspace.
* `supabase_setup.sql` - Database schema and configuration for Supabase.
